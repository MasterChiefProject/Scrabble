About this demo

This browser version mirrors the original project's 15×15 board, 98-tile bag, letter values, premium-square layout, connectivity rules, and score calculation. It is a JavaScript adaptation for GitHub Pages, not a JVM runtime.

Dictionary lookup is intentionally not enforced here. The original Java project implements dictionary querying separately with caches, a Bloom filter, file search, and a TCP server.
